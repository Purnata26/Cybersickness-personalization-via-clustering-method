# Unsupervised Clustering for Personalized Cybersickness Detection in VR

This repository contains the implementation of unsupervised clustering and personalized learning approaches for cybersickness detection using multimodal physiological and behavioral data collected during Virtual Reality (VR) exposure.



---

# Features

- ECG, GSR, eye-tracking, and head-tracking integration
- Unsupervised clustering pipelines
- Personalized cybersickness prediction
- Generalized vs personalized model comparison
- Fully unsupervised cybersickness detection



# Datasets

The framework was evaluated on two public VR datasets.

## Dataset 1
Includes:
- ECG
- GSR
- Eye tracking
- Head tracking
- FMS labels
- SSQ scores

## Dataset 2
Includes:
- GSR
- Heart Rate (HR)
- Eye tracking
- Head tracking
- FMS labels
- SSQ
